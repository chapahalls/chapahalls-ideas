# rodar-web: decisões

Decisões que valem só para este repositório. Uma linha por decisão, a mais nova no topo. Decisão que muda o plano (fases, critérios, escopo) vai por `/adr` em [`docs/adr/`](../../docs/adr/), e aqui fica só o link.
