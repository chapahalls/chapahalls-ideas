# Evidence

Written only by the `verifier` agent, one report per phase close: `phase-<n>.md`, plus raw artifacts (logs, command output, screenshots) in `phase-<n>/`.

Each criterion from `PLAN.md` gets one verdict: **PROVEN** (with the evidence), **FAILED** (with the output) or **NEEDS HUMAN** (can't be checked from a terminal, e.g. how a screen looks).
